### 2. 本机 HEARTBEAT.md 被 static/ 覆盖 → 本机特有注意事项丢失
- 现象：00:16 同步日志出现"已更新本机 HEARTBEAT.md（来自 static/）"
  → 本地工作区 HEARTBEAT.md 从 181 行变成 98 行，

- 原因：同步脚本**总是**用 static/ 覆盖本机文件，而 static/ 由 bot2 统一维护
  → 本机特有的内容只存在于本地 git 历史，从没进过共享仓库
- 修复：把本机特有段落写回本地 HEARTBEAT.md（不提交到 static），
  并在 memory/2026-10-23.md 留档
- ⚠️ 结构性提醒：**本机专属信息不能只存在于本地 git 历史**，
  否则下次 sync 覆盖后就没了；要么进 memory/（会同步到共享仓库），
  要么在脚本里排除 HEARTBEAT.md 的覆盖

### 3. 结构性修复：static 覆盖后自动恢复本机段落
- 新增 `/root/.openclaw/HEARTBEAT-local/<机器名>.local.md`
  （本机 = `/root/.openclaw/HEARTBEAT-local/bot5.local.md`）
