## 版本概述

### v1.1.0 目标

v1.1.0 版本聚焦于**系统扩展性**和**性能提升**，在保持 v1.0.9 现有功能稳定的基础上，引入三大核心模块：

1. **用户管理增强** - 完善的用户生命周期管理
2. **认证授权增强** - 企业级安全和细粒度权限
3. **通知系统** - 多渠道实时通知能力

### 核心价值

- 🚀 **性能提升 50-98%**（基于性能优化报告）
- 🔒 **安全性增强** - OAuth 2.0 + 细粒度 RBAC
- 📢 **实时通知** - WebSocket + 邮件 + 推送
- 🏗️ **可扩展架构** - 微服务化准备

### 版本对比

| 特性 | v1.0.9 | v1.1.0 |
|------|--------|--------|
| 用户管理 | 基础 CRUD | 完整生命周期管理 |
| 认证方式 | JWT | JWT + OAuth 2.0 + SSO |
| 权限系统 | RBAC (v2) | RBAC (v2) + 属性权限 (ABAC) |
| 通知系统 | 基础 WebSocket | 多渠道 + 通知中心 |
| 缓存策略 | 部分 Redis | 多级缓存架构 |
| 消息队列 | 内存队列 | Redis Queue + Bull |
| 数据库 | 单体 SQLite | 准备分库分表 |
| API 版本 | 无版本控制 | v1.1.0 API 命名空间 |

#### 2.4 认证流程

**OAuth 2.0 认证流程**
```
用户 → GET /api/v1/auth/oauth/google
       ↓ (重定向到 Google)
Google → 用户授权
       ↓ (回调)
GET /api/v1/auth/oauth/google/callback?code=xxx
       ↓ (交换 access token)
后端 → 获取用户信息
       ↓ (查找或创建用户)
后端 → 生成 JWT
       ↓ (返回给前端)
前端 → 存储 token
       ↓ (后续请求携带 token)
API → 验证 token
```

**2FA 认证流程**
```
用户 → POST /api/v1/auth/login
       ↓ (输入邮箱密码)
后端 → 验证成功
       ↓ (检查是否启用 2FA)
后端 → 返回 { requires_2fa: true, temp_token: xxx }
       ↓
用户 → GET /api/v1/auth/2fa/setup  (首次设置)
       ↓
用户 → 输入 TOTP 码
       ↓
POST /api/v1/auth/2fa/verify
       ↓ (验证成功)
后端 → 返回最终 JWT
```

```typescript
// 检测异常登录行为
async function detectSuspiciousLogin(
  userId: string,
  ipAddress: string,
  userAgent: string
): Promise<boolean> {
  const recentLogins = await getRecentLogins(userId, 7); // 最近 7 天

  // 检测 1: 异常地理位置
  const locations = recentLogins.map(l => l.location);
  if (isUnusualLocation(locations, ipAddress)) {
    return true;
  }

  // 检测 2: 异常设备
  const devices = recentLogins.map(l => l.device_type);
  if (isUnusualDevice(devices, userAgent)) {
    return true;
  }

  // 检测 3: 异常时间（凌晨 2-5 点）
  const hour = new Date().getHours();
  if (hour >= 2 && hour <= 5 && !isNightUser(userId)) {
    return true;
  }

  return false;
}
```

**通知缓存**
```typescript
// 未读通知数缓存
const UNREAD_COUNT_CACHE_KEY = 'notifications:unread:count:';

export async function getUnreadCount(
  userId: string,
  forceRefresh: boolean = false
): Promise<number> {
  const redis = getRedisClient();
  const cacheKey = `${UNREAD_COUNT_CACHE_KEY}${userId}`;
  const CACHE_TTL = 2 * 60; // 2 分钟

  if (!forceRefresh) {
    const cached = await redis.get(cacheKey);
    if (cached !== null) {
      return parseInt(cached, 10);
    }
  }

  // 查询数据库
  const db = await getDatabaseAsync();
  const count = db.queryOne(
    'SELECT COUNT(*) as count FROM notifications WHERE user_id = ? AND read = FALSE',
    [userId]
  ) as { count: number };

  // 写入缓存
  await redis.setex(cacheKey, CACHE_TTL, count.toString());

  return count.count;
}

// 创建通知时失效缓存
export async function invalidateUnreadCountCache(userId: string): Promise<void> {
  const redis = getRedisClient();
  await redis.del(`${UNREAD_COUNT_CACHE_KEY}${userId}`);
}
```

```typescript
// 批量发送广播通知（避免 N+1 查询）
async function broadcastNotification(
  data: BroadcastNotificationData
): Promise<BroadcastResult> {
  // 1. 批量创建通知记录
  const userIds = data.target_user_ids;
  const notifications = userIds.map(userId => ({
    id: generateId(),
    user_id: userId,
    ...data.notification,
    created_at: new Date().toISOString(),
  }));

  const { batchInsert } = await import('@/lib/db/batch-operations');
  await batchInsert('notifications', notifications, {
    batchSize: 1000,
    useTransaction: true,
  });

  // 2. 批量生成邮件任务
  const emailTasks = notifications
    .filter(n => data.channels.includes('email'))
    .map(n => ({
      id: generateId(),
      type: 'email',
      data: {
        to: await getUserEmail(n.user_id),
        subject: n.title,
        body: n.body,
      },
      priority: data.priority === 'urgent' ? 'high' : 'normal',
    }));

  // 3. 批量加入队列
  await notificationQueue.bulkAdd(emailTasks);

  return {
    total: userIds.length,
    success: userIds.length,
    failed: 0,
  };
}
```

#### 3.2 L1 缓存（内存）

**用途**: 热点数据，极快访问

**缓存内容**:
- 用户会话（当前用户）
- 用户权限（RBAC 角色和权限）
- 用户偏好设置
- 应用配置

**TTL 策略**:
- 会话数据: 5 分钟
- 权限数据: 10 分钟
- 配置数据: 30 分钟

**实现**:
```typescript
// src/lib/cache/l1-cache.ts
class L1Cache {
  private cache = new Map<string, { value: unknown; expires: number }>();
  private maxEntries = 1000;

  set(key: string, value: unknown, ttl: number): void {
    // LRU 淘汰策略
    if (this.cache.size >= this.maxEntries) {
      const firstKey = this.cache.keys().next().value;
      this.cache.delete(firstKey);
    }

    this.cache.set(key, {
      value,
      expires: Date.now() + ttl * 1000,
    });
  }

  get(key: string): unknown | null {
    const entry = this.cache.get(key);
    if (!entry) return null;

    // 检查过期
    if (Date.now() > entry.expires) {
      this.cache.delete(key);
      return null;
    }

    // 更新访问时间（LRU）
    const value = entry.value;
    this.cache.delete(key);
    this.cache.set(key, entry);

    return value;
  }
}

export const l1Cache = new L1Cache();
```

```typescript
// 空值缓存（防止缓存穿透）
export async function getUserWithCache(userId: string): Promise<User | null> {
  const cacheKey = CACHE_KEYS.USER(userId);
  const redis = getRedisClient();

  // 尝试从缓存获取
  const cached = await redis.get(cacheKey);
  if (cached) {
    if (cached === 'NULL') {
      return null; // 空值标记
    }
    return JSON.parse(cached);
  }

  // 查询数据库
  const user = await getUserById(userId);

  // 写入缓存（包含空值）
  if (user) {
    await redis.setex(cacheKey, 300, JSON.stringify(user));
  } else {
    await redis.setex(cacheKey, 60, 'NULL'); // 空值缓存 1 分钟
  }

  return user;
}
```

**缓存雪崩保护**:
```typescript
// 随机 TTL 偏移（防止缓存雪崩）
function getRandomTTL(baseTTL: number, variance: number = 0.1): number {
  const varianceMs = baseTTL * variance * 1000;
  const offset = Math.floor(Math.random() * varianceMs * 2) - varianceMs;
  return Math.max(1, baseTTL + Math.floor(offset / 1000));
}

// 使用示例
const ttl = getRandomTTL(300); // 5 分钟 ± 10%
await redis.setex(key, ttl, value);
```

```typescript
// src/lib/queue/queue-manager.ts
import Queue from 'bull';
import { getRedisClient } from '@/lib/redis';

interface QueueConfig {
  name: string;
  defaultJobOptions: {
    attempts: number;
    backoff: {
      type: 'exponential';
      delay: number;
    };
    removeOnComplete: number;
    removeOnFail: number;
  };
}

export class QueueManager {
  private queues: Map<string, Queue> = new Map();

  constructor() {
    this.initializeQueues();
  }

  private initializeQueues(): void {
    const redis = getRedisClient();

    const queueConfigs: QueueConfig[] = [
      {
        name: 'email',
        defaultJobOptions: {
          attempts: 3,
          backoff: { type: 'exponential', delay: 2000 },
          removeOnComplete: 100,
          removeOnFail: 50,
        },
      },
      {
        name: 'notification',
        defaultJobOptions: {
          attempts: 3,
          backoff: { type: 'exponential', delay: 1000 },
          removeOnComplete: 500,
          removeOnFail: 100,
        },
      },
      {
        name: 'analytics',
        defaultJobOptions: {
          attempts: 2,
          backoff: { type: 'exponential', delay: 5000 },
          removeOnComplete: 1000,
          removeOnFail: 200,
        },
      },
      {
        name: 'backup',
        defaultJobOptions: {
          attempts: 1,
          removeOnComplete: 10,
          removeOnFail: 10,
        },
      },
    ];

    for (const config of queueConfigs) {
      const queue = new Queue(config.name, {
        redis: {
          host: process.env.REDIS_HOST || 'localhost',
          port: parseInt(process.env.REDIS_PORT || '6379'),
          password: process.env.REDIS_PASSWORD,
          db: parseInt(process.env.REDIS_DB || '0'),
        },
        defaultJobOptions: config.defaultJobOptions,
      });

      // 设置事件监听
      this.setupQueueListeners(queue);

      this.queues.set(config.name, queue);
    }
  }

  private setupQueueListeners(queue: Queue): void {
    queue.on('completed', (job) => {
      logger.debug(`Job ${job.id} completed in queue ${queue.name}`);
    });

    queue.on('failed', (job, err) => {
      logger.error(`Job ${job?.id} failed in queue ${queue.name}:`, err);
    });

    queue.on('stalled', (job) => {
      logger.warn(`Job ${job?.id} stalled in queue ${queue.name}`);
    });
  }

  getQueue(name: string): Queue | undefined {
    return this.queues.get(name);
  }
}

export const queueManager = new QueueManager();
```

#### 2.2 RESTful 设计原则

**资源命名**:
- 使用复数名词: `/api/v1/users` (不是 `/api/v1/user`)
- 层级关系: `/api/v1/users/:userId/notifications`
- 过滤参数: `/api/v1/users?status=active&role=admin`

**HTTP 方法**:
- `GET`: 查询资源（幂等）
- `POST`: 创建资源
- `PUT`: 完整更新资源（幂等）
- `PATCH`: 部分更新资源（幂等）
- `DELETE`: 删除资源（幂等）

**状态码**:
- `200 OK`: 成功
- `201 Created`: 创建成功
- `204 No Content`: 删除成功（无返回体）
- `400 Bad Request`: 请求参数错误
- `401 Unauthorized`: 未认证
- `403 Forbidden`: 无权限
- `404 Not Found`: 资源不存在
- `409 Conflict`: 资源冲突（如邮箱已存在）
- `422 Unprocessable Entity`: 验证失败
- `429 Too Many Requests`: 限流
- `500 Internal Server Error`: 服务器错误

---

#### 2.3 查询参数设计

**通用参数**:
- `page`: 页码（默认 1）
- `limit`: 每页数量（默认 20，最大 100）
- `sort_by`: 排序字段
- `sort_order`: 排序方向（`asc` / `desc`）
- `fields`: 返回字段（逗号分隔）
- `include`: 关联资源（逗号分隔）
- `q`: 全文搜索

**过滤参数**:
- 按状态过滤: `?status=active`
- 按范围过滤: `?created_after=2026-01-01&created_before=2026-12-31`
- 按枚举过滤: `?role=admin,manager`
- 按关系过滤: `?department_id=xxx`

**示例**:
```bash
# 获取活跃管理员用户，按创建时间倒序
GET /api/v1/users?status=active&role=admin&sort_by=created_at&sort_order=desc

# 获取用户的通知，仅返回未读的
GET /api/v1/users/:userId/notifications?read=false

# 搜索用户，返回指定字段
GET /api/v1/users?q=John&fields=id,name,email&include=department,groups
```
