**当前实现:** `/src/app/api/backup/route.ts`
- **当前耗时:** ~2000ms
- **瓶颈分析:**

1. **N+1 查询问题** (已部分优化)
   - 对每个表执行 2 次查询 (SELECT * + COUNT)
   - 18 个表 = 36 次数据库查询

2. **全表扫描**
   - `SELECT * FROM table` 导出所有数据
   - 没有利用索引
   - 所有表没有任何索引

3. **序列化开销**
   - JSON.stringify 所有数据
   - 数据库文件 220KB

4. **文件 I/O**
   - 写入 JSON 到磁盘
   - 计算校验和

**性能估算:**
- 查询开销: ~1200ms (36 queries × 33ms avg)
- 序列化: ~500ms
- 文件 I/O: ~200ms
- 其他: ~100ms

### 批量用户查询性能瓶颈

**当前实现:** `/src/app/api/users/route.ts`
- **当前耗时:** ~500ms (100 users)
- **瓶颈分析:**

1. **应用层过滤**
   - `getAllUsers()` 获取所有用户
   - 搜索在内存中进行 (JavaScript filter)
   - 排序在内存中进行 (JavaScript sort)

2. **缺少索引**
   - users 表只有 email 索引
   - status, role 查询全表扫描
   - last_login_at 有索引但可能未被优化

3. **无查询缓存**
   - 每次请求都查询数据库
   - 相同查询重复执行

**性能估算:**
- 数据库查询: ~200ms (全表扫描)
- 应用过滤: ~150ms
- 应用排序: ~100ms
- 分页处理: ~50ms

## 🎯 优化方案

### 1. 备份 API 优化 (2000ms → 300ms)

#### 优化措施

##### A. 消除 N+1 查询 (预计节省 1000ms)

**优化前:**
```typescript
for (const table of tables) {
  const tableData = await db.query(`SELECT * FROM ${table}`);
  const count = await db.query(`SELECT COUNT(*) FROM ${table}`);
}
```

**优化后:**
```typescript
// 单次 UNION ALL 查询获取所有表的行数
const countQuery = tables.map(t =>
  `SELECT '${t}' as table_name, COUNT(*) as row_count FROM ${t}`
).join(' UNION ALL ');

const rowCountData = db.prepare(countQuery).all();

// 单次批量导出
for (const table of tables) {
  const tableData = db.prepare(`SELECT * FROM ${table}`).all();
  backupData[table] = tableData;
  recordCounts[table] = tableData.length; // 使用数组长度
}
```

**效果:** 从 36 次查询减少到 19 次查询 (-17 次查询)

##### B. 优化 SQLite 配置 (预计节省 200ms)

```sql
-- 启用内存映射 (加快读取)
PRAGMA mmap_size = 268435456;  -- 256 MB

-- 临时表使用内存 (加快排序)
PRAGMA temp_store = 2;  -- MEMORY

-- 增加缓存大小
PRAGMA cache_size = -64000;  -- 64 MB

-- 异步写入 (已启用,但确认)
PRAGMA synchronous = NORMAL;  -- 1
```

##### C. 实现查询结果缓存 (预计节省 300ms)

```typescript
// 简单的内存缓存
const backupCache = new Map<string, { data: any; timestamp: number }>();
const CACHE_TTL = 5 * 60 * 1000; // 5 分钟

async function createBackupWithCache(): Promise<BackupMetadata> {
  const cacheKey = 'backup_latest';
  const cached = backupCache.get(cacheKey);

  if (cached && Date.now() - cached.timestamp < CACHE_TTL) {
    logger.info('Returning cached backup');
    return cached.data;
  }

  const backup = await createBackup();
  backupCache.set(cacheKey, { data: backup, timestamp: Date.now() });
  return backup;
}
```

```typescript
async function getUsersWithCursor(cursor: string | null, limit: number) {
  let sql = 'SELECT * FROM users';
  const params = [];

  if (cursor) {
    sql += ' WHERE created_at < ?';
    params.push(cursor);
  }

  sql += ' ORDER BY created_at DESC LIMIT ?';

  };
}
```

```typescript
export async function getUsersOptimized(options: {
  status?: UserStatus;
  role?: UserRole;
  search?: string;
  page: number;

  let sql = 'SELECT * FROM users WHERE 1=1';
  const params: any[] = [];

  if (options.status) {

    params.push(options.status);
  }

    params.push(options.role);
```

### 阶段 5: 缓存实现 (2-3 天)

**文件:** `src/lib/db/cache.ts` (创建)

```typescript
import { LRUCache } from 'lru-cache';
import { logger } from '@/lib/logger';

/**
 * Simple LRU cache for query results
 */
export class QueryCache {
  private cache: LRUCache<string, { data: any; timestamp: number }>;
  private ttl: number;

  constructor(options: { max: number; ttl: number }) {
    this.cache = new LRUCache({ max: options.max });
    this.ttl = options.ttl;
  }

  get(key: string): any | null {
    const entry = this.cache.get(key);
    if (!entry) return null;

    if (Date.now() - entry.timestamp > this.ttl) {
      this.cache.delete(key);
      return null;
    }

    logger.debug('Cache hit', { key });
    return entry.data;
  }

  set(key: string, data: any): void {
    this.cache.set(key, { data, timestamp: Date.now() });
    logger.debug('Cache set', { key });
  }

  invalidate(pattern?: string): void {
    if (pattern) {
      // Invalidate all keys matching pattern
      for (const key of this.cache.keys()) {
        if (key.includes(pattern)) {
          this.cache.delete(key);
        }
      }
    } else {
      this.cache.clear();
    }
    logger.debug('Cache invalidated', { pattern });
  }

  getStats() {
    return {
      size: this.cache.size,
      maxSize: this.cache.max,
      calcSize: this.cache.calculatedSize,
    };
  }
}

// Global cache instances
export const userQueryCache = new QueryCache({ max: 500, ttl: 60 * 1000 }); // 1 minute
export const backupCache = new QueryCache({ max: 10, ttl: 5 * 60 * 1000 }); // 5 minutes
export const auditLogCache = new QueryCache({ max: 100, ttl: 30 * 1000 }); // 30 seconds
```
