## 🚨 暴露的 3 个致命 bug (事后再看)

### Bug 1: state 写盘失败 → MAX_POS 失效
- `save_state()` 用 `os.replace(tmp, STATE_FILE)`
- 心跳当时 mtime 停在 05:27:04 (首笔开仓时)
- **疑因**: tmp 文件创建路径 + process 死后 .tmp 残留导致 replace 失败

- **实仓开仓 28 笔**, paper 同期 4 笔
- 持续 1.5h 才被 heartbeat 发现

### Bug 2: reduceOnly + hedge mode 互斥
- hedge mode 下 reduceOnly 参数 = APIError(-1106): "Parameter 'reduceonly' sent when not required"
- 我的 `place_order(reduce_only=True)` 错误地塞 reduceOnly
- 后果: 平仓 silent fail → 持仓不释放 → 下一笔开新仓
- **手动 close 时我也踩了同一个坑**, 后才 retry 不传 reduceOnly 才 OK

### Bug 3: VR 过滤跟 paper 不一致
- paper S2 VR 是 `vol_ratio = 1.0` placeholder, **从不查 VR**
- live 我加了 `VR >= 4` filter → 30 min 内所有 signal 全 skip (实际 VR 1.0~2.1)
- 修了, 但修完又触发 Bug 1 → 仓持续开
- 根因: 我的 live 偏离 paper 太多, **paper 转 live 应该 1:1 clone, 不"优化"**

### Bug 4 (事后加): calc_qty 中 price 极低 → qty 过大
