## Lessons from today

### Lesson 1: Read owner intent literally, don't extrapolate
- Owner said "用自己本地的语言" + "不是CN而是中文" — I read it backwards twice
- "不是 X 而是 Y" in Chinese = "don't use X, use Y" — clear sentence, my brain inverted it
- **When ambiguous, ask before mass-applying changes to 50 files**

### Lesson 2: mix-blend-mode is "fake transparent"
- Looks clever on dark+light bg sections but reads as broken/illegible to non-designers
- Owner (non-designer eye) flagged it as "transparent, 不太科学" immediately
- **Solid bg + border beats blend mode for fixed UI elements**

### Lesson 3: nginx location priority traps
- `~ \.html$` regex catch-all beats `^~ /<lang>.html` prefix
- Solution: use exact `location = /<lang>.html` (highest priority) or `^~` + ordering
- When regex + prefix compete: **first match wins for regex**, prefix needs `^~` to lock

### Lesson 4: nginx reload silently fails sometimes
- After `nginx -s reload`, master reloads but worker doesn't re-spawn → old config serves
- Symptom: nginx -T shows new config, but HTTP responses are from old
- Fix: `kill -HUP $(cat /var/run/nginx.pid)` then wait, or full restart
- **Always test after reload, don't trust exit code**

### Lesson 5: 14GB site "move" via nginx rewrite
- Physical copy of erhu-brand = 14GB, 1939 files, Next.js proxy, AdSense sub_filter
- Solved with `location ^~ /7zi/ { alias /var/www/erhu-brand/; }` — zero copies
- **Alias is the right tool when "subdirectory" is about URL structure, not file layout**
